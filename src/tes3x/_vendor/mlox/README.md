# mlox 1.0.3

The sorting core of [mlox](https://github.com/mlox/mlox) 1.0.3, MIT-licensed (`LICENSE.txt`), so
TES3X can sort plugins without installing mlox and its GUI dependencies. The files are unmodified
except `resources.py`, which is replaced, and one regex in `configHandler.py`, made a raw string.
The rules (`mlox_base.txt`) are not included; TES3X downloads them from the
[mlox-rules project](https://github.com/DanaePlays/mlox-rules).
