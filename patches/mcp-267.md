# UI pixel alignment

Patch key: `mcp-267`

The menu camera places text, icons and window frames between screen pixels, which can blur their
edges. This patch aligns both UI cameras to the pixel grid, making those elements sharper at the
same output resolution. It does not change the size of menus or fonts.

See the [patch table](../docs/patches.md) for availability and selection.

## How it works

The engine rounds the UI camera's projection distance and resets its horizontal and vertical
offsets to zero during setup and resolution refresh. The patch retains the fractional distance,
sets both offsets to minus half a pixel on refresh, and preserves those offsets during startup.
The two menu camera paths receive the same correction.
