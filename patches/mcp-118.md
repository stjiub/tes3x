# Airborne item drop fix

Patch key: `mcp-118`

Dropping an item in third person while levitating or falling can place it far from the player,
near the world origin. This patch keeps the dropped item near the player so it can be recovered.

## How it works

The drop placement code can return a ground position far below an airborne player when its
raycasts find no nearby surface. The patch checks the final position and uses the player's
position if the drop would be more than 128 game units away horizontally or below them.

See the [patch table](../docs/patches.md) for availability and selection.
