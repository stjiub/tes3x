# Confiscated item fix

Patch key: `mcp-115`

Paying a fine or serving a sentence clears the theft records for items the guards confiscate. A later arrest therefore does not take another copy of the same item just because one was stolen before.

Merchants still recognize items stolen from themselves, but no longer seize a player's item solely because an item of the same kind was taken from a faction-owned container elsewhere. Picking up an item owned by a dead NPC no longer marks that item as stolen; being seen taking it may still be a crime.

See the [patch table](../docs/patches.md) for availability and selection.

## How it works

The guard paths clear the confiscated item's stolen-owner list after finding a nonempty list. The world pickup path checks the owner's death count before adding a theft record. The barter and merchant menu paths ignore the faction-owner lookup while retaining the merchant-owner lookup.
