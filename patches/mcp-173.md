# NPC faction rank persistence

Patch key: `mcp-173`

When a script uses `RaiseRank` or `LowerRank` on an NPC, the changed faction rank is saved with
that actor. This prevents the rank from reverting after loading a save, which can disrupt quests
that change an NPC's standing.

## How it works

The Xbox engine already changes the rank in memory, but marks the script context for saving. The
patch marks the NPC reference before changing its rank. See the [patch table](../docs/patches.md)
for availability and selection.
