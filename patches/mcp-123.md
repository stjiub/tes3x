# PlaceItem persistence

`PlaceItem` and `PlaceItemCell` can create a reference in a cell the player has not visited. The
retail insertion path initializes the reference and adds it to the cell, but does not mark that
cell as changed. The save writer can therefore omit the cell and lose the new reference. This
patch marks the cell so the placed object is saved.

See the [patch table](../docs/patches.md) for availability and selection.

## How it works

Both commands share an Xbox helper at `0x00138AA0`. Immediately before its call to
`Cell::addReference` at `0x00138C17`, a payload wrapper (`hooks/tes3xmcp123.c`) sets bit `0x02` at
offset `0x08` in the destination cell and then tail-calls the original method. This matches the
dirty mark used by the cell save path and leaves reference creation unchanged.
