# Separate axe inventory sounds

Patch key: `mcp-114`

The axe inventory lookup uses a sound name shared with another weapon class. This patch gives axes their own sound names, so a mod can supply separate axe sounds. Patch for Purists supplies the needed sound records.

## How it works

The engine's weapon sound name table labels the axe entry `Item Weapon Blunt`. The patch changes that entry to `Item Weapon Axe`; the existing Up and Down lookup then finds the separate records.

Enable this only with a mod that adds `Item Weapon Axe Up` and `Item Weapon Axe Down`. Without those records, axes have no inventory sounds.
