# RemoveItem weight fix

Patch key: `mcp-160`

When a script removes an item the character does not carry, the game still lowers the character's
encumbrance by that item's weight. A mod that removes items without checking first can leave the
player carrying less than the game thinks, or more, until the inventory is rebuilt. With the patch,
encumbrance changes only for an item that was actually removed. `RemoveItem` and dropping use the
same code and are both covered.

## How it works

The removal routine takes the weight off first and looks for the item's stack afterwards. The patch
reorders it so the lookup comes first and the weight is taken off only when the stack is found. No
extra code is added. See the [patch table](../docs/patches.md) for availability and selection.
