# Script expression parser fix

Patch key: `mcp-141`

Compiled scripts can misread the operand stored after a function opcode. `Random` with an argument such as 256 can then return a value outside its range or crash while evaluating the expression. The same parser rejects local variable 34 inside some expressions, and reference resolution can lose a global value assigned to a high-index local.

Scripts that use these forms can evaluate as written.

See the [patch table](../docs/patches.md) for availability and selection.

## How it works

The parser copies each function token with its full operand, including `Random`'s two extra bytes. It accepts local 34 in expression token walks and passes the complete expression length to script reference resolution.
