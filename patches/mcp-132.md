# Improved animation support

Patch key: `mcp-132`

Scripted `PlayGroup` and `LoopGroup` animations now play across all three humanoid body layers. The patch also lets humanoid animation files assign an added bone to a body layer by including a standard bone name in its name, and updates a scripted third person player animation each frame. This enables animation mods whose extra bones or full body sequences do not work in the retail engine.

See the [patch table](../docs/patches.md) for availability and selection.

## How it works

The script handlers call the engine's animation player once per layer. Bone setup matches a standard bone name within each name from the animation file. When the player has a scripted animation, the main loop updates the player's reference after the normal idle update.
