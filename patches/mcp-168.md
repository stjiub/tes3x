# Neutral NPC death blame fix

Patch key: `mcp-168`

When another actor's area spell kills a neutral NPC, the game can charge the player with murder.
This patch prevents that charge when the NPC was not fighting the player. It is useful around
guards and spellcasting enemies, whose attacks can catch bystanders.

## How it works

The crime handler checks whether the victim was targeting the player. If that check fails, the
original code can continue into the murder report when the victim has no target. The patch exits
the handler at that point, leaving the other crime checks intact. See the
[patch table](../docs/patches.md) for availability and selection.
