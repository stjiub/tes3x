# Safe corpse disposal

Patch key: `mcp-149`

An actor's contents menu can offer corpse disposal during its death animation. Disposing it then
can prevent death scripts and spell cleanup from running. This patch removes the disposal action
until death processing finishes. Looting remains available.

## How it works

The contents menu checks the actor's state each time it opens. State `0x13` clears the disposal
flag; state `0x12` enables it as before. Other actor states keep the retail behavior.

See the [patch table](../docs/patches.md) for availability and selection.
