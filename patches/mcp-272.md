# Improved inventory filters

Patch key: `mcp-272`

The Magic filter in the inventory and barter menus groups soul gems with potions and scrolls.
Enchanted equipment stays in its equipment category, so it does not crowd the Magic view.

## How it works

Both menus apply the same item-category filter. The patch reuses the engine's soul-gem check
and changes the filter result for soul gems and enchanted equipment when Magic is selected.
See the [patch table](../docs/patches.md) for availability and selection.

The engine's soul-gem check recognizes its six built-in soul-gem records. New gems added as
separate records by a mod are not grouped with them.
