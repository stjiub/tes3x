# Position actor initialization

Patch key: `mcp-125`

`Position` and `PositionCell` can move an NPC from an unvisited cell into the current cell. Retail
moves the reference but returns before the existing script-attachment path, so the NPC's script
remains uninitialized until a reload. Dialogue with that NPC can then crash. Retail also removes a
moved actor from collision when its destination is not loaded, but does not register it when the
destination is loaded, allowing projectiles and magic to pass through the actor. This patch
attaches the script and registers the collision.

See the [patch table](../docs/patches.md) for availability and selection.

## How it works

The two Xbox command paths at `0x0013DB68` and `0x0013DC9A` preserve the moved reference in `esi`
and join the engine's existing script-attachment path at `0x0014125D` after the shared move helper
returns (`hooks/tes3xmcp125.c`). In that helper, the collision branch at `0x00138C87` now selects
the existing `MobManager::addMob` or `MobManager::removeMob` method from the destination-cell
residency flag.
